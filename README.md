## 🛠️ Cara Menjalankan Lokal

```bash
# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build untuk production
npm run build

# Jalankan production build
npm start
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
