## 🚀 Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 📖 **310+ Chapter Komik** | Setiap chapter adalah panel komik interaktif bergaya manga/webtoon |
| 🔍 **Pencarian Chapter** | Tekan `Ctrl+K` untuk membuka Command Palette & cari chapter manapun |
| 🌐 **Multi-Bahasa** | Tersedia dalam 10+ bahasa: ID, EN, JA, ZH, AR, MS, KO, FR, DE, ES |
| 📊 **Visitor Real-time** | Penghitung pengunjung aktif dengan data langsung dari API |
| 🎬 **Animasi GIF-like** | Sprite animation, matrix rain, partikel, typing loop, countup |
| 🎴 **Panel Flip Card** | Kartu interaktif yang bisa dibalik untuk reveal konten tersembunyi |
| 💡 **200 Inovasi** | Daftar 200 ide/inovasi lengkap dengan status dan detail expandable |
| 🎭 **Mode Rahasia** | Easter egg tersembunyi dengan kombinasi tombol khusus |
| 🎵 **Pemutar Musik** | Background music player built-in |
| 🌙 **Dark Mode** | Toggle dark/light mode di navbar |

| `↑ ↓` | Navigasi hasil pencarian |

| `Esc` | Tutup dialog/modal |

## 🛠️ Cara Menjalankan

```bash
# Clone repository
git clone https://github.com/rizki-habibi/rizki-habibi-portofolio-.git

# Masuk ke folder
cd portofolio

# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build production
npm run build
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
